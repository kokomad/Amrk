# منفّذ — أتمتة الأوامر المتكررة على أندرويد

تطبيق يجدول أوامر الجوال وينفّذها تلقائيًا: رسائل واتساب/SMS، اتصال، الواي فاي، بيانات الجوال، التبديل بينهما، البلوتوث، الكشاف، وضع الصوت، فتح تطبيق أو رابط، وتذكيرات.
لكل أمر: تاريخ البدء، ساعة أول تنفيذ، عدد المرات في اليوم والفاصل بينها، عدد الأيام، أيام الأسبوع، وقت الإيقاف التلقائي، وحد أقصى للتنفيذ.

## البناء على GitHub (بدون Android Studio)
1. أنشئ مستودعًا جديدًا على GitHub وارفع كل ملفات هذا المجلد (مع مجلد `.github`).
2. افتح تبويب **Actions** ← سيعمل **Build APK** تلقائيًا (أو شغّله يدويًا من *Run workflow*).
3. بعد انتهائه (≈ 5 دقائق) افتح التشغيل ونزّل الملف من **Artifacts** ← `Monaffeth-APK` ← ثبّت `Monaffeth.apk`.
4. للنشر كإصدار: أنشئ وسمًا `v1.0.0` وسيُرفق الملف تلقائيًا في **Releases**.

### توقيع ثابت (اختياري، لتحديث التطبيق فوق القديم)
أضف في Settings ← Secrets: `KEYSTORE_BASE64` (ملف jks بصيغة base64) و`KEYSTORE_PASSWORD` و`KEY_ALIAS` و`KEY_PASSWORD`.
بدونها يُوقَّع الملف بمفتاح تجريبي يتغير كل بناء (يلزم حذف النسخة القديمة قبل التثبيت).

## بعد التثبيت
افتح تبويب **الصلاحيات** وامنح: خدمة الوصول، العرض فوق التطبيقات، المنبّهات الدقيقة، استثناء البطارية.
على أندرويد 13+ إن كانت خدمة الوصول رمادية: معلومات التطبيق ← ⋮ ← السماح بالإعدادات المقيّدة.

## حدود يفرضها أندرويد (مهم)
- لا يسمح أندرويد 10+ لأي تطبيق عادي بتبديل الواي فاي/البيانات برمجيًا؛ لذلك يفتح التطبيق لوحة الإعدادات ويضغط المفتاح عبر خدمة الوصول (قد تختلف النتيجة بين الشركات).
- واتساب لا يوفّر إرسالًا صامتًا؛ يُفتح الدردشة ويُضغط زر الإرسال تلقائيًا، فتظهر الشاشة لثوانٍ.
- الأوامر التي تفتح شاشة تحتاج جهازًا بدون قفل آمن (بصمة/PIN)؛ قفل «السحب» أو بدون قفل يعمل.
- الإنترنت غير مطلوب؛ كل البيانات محلية.
